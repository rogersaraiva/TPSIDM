Já configurei o seu projeto Android em Kotlin com a biblioteca Retrofit + Gson e as permissões de rede necessárias para consumir dados JSON do seu backend em PHP.
Abaixo encontra o guia completo passo a passo de como criar a Base de Dados MySQL, os Scripts PHP e como funciona a integração.
+-------------------+      HTTP GET (JSON)     +-------------------+     SQL Query     +-------------------+
|  App Android      |  --------------------->  |  Servidor Web     |  -------------->  |  Base de Dados    |
|  (Kotlin/Compose) |  <---------------------  |  (Scripts PHP)    |  <--------------  |  (MySQL / MariaDB)|
+-------------------+      Resposta JSON       +-------------------+     Resultado     +-------------------+

Passo 1: Criar a Base de Dados MySQL
No seu servidor MySQL (via phpMyAdmin no XAMPP/WAMP ou no seu alojamento web), crie a base de dados meu_restaurante e execute a seguinte instrução SQL:

-- 1. Criar a base de dados
CREATE DATABASE IF NOT EXISTS meu_restaurante DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE meu_restaurante;

-- 2. Criar a tabela de pratos
CREATE TABLE IF NOT EXISTS pratos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    descricao TEXT,
    preco DECIMAL(10,2) NOT NULL,
    categoria VARCHAR(50) NOT NULL,
    imagem VARCHAR(10) NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Passo 2: Criar os Ficheiros PHP (API Backend)
Dentro da pasta do seu servidor web (ex: htdocs/meu_restaurante/ no XAMPP ou www/meu_restaurante/ no WAMP), crie estes 2 ficheiros:

<?php
$host = "localhost";
$user = "root";      // Utilize o seu utilizador MySQL
$pass = "";          // Utilize a sua palavra-passe MySQL
$db   = "meu_restaurante";

try {
    $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    echo json_encode(["erro" => "Falha na conexão: " . $e->getMessage()]);
    exit;
}
?>

2. obter_pratos.php

<?php
header('Content-Type: application/json; charset=utf-8');
require_once 'conexao.php';

try {
    $stmt = $pdo->prepare("SELECT id, nome, descricao, preco, categoria, imagem FROM pratos");
    $stmt->execute();
    
    $pratos = $stmt->fetchAll(PDO::ATTR_FETCH_ASSOC);

    // Garante que o preço seja retornado como float/double para o JSON
    foreach ($pratos as &$prato) {
        $prato['id'] = (int)$prato['id'];
        $prato['preco'] = (float)$prato['preco'];
    }

    echo json_encode($pratos, JSON_UNESCAPED_UNICODE);
} catch (Exception $e) {
    http_response_code(500);
    echo json_encode(["erro" => $e->getMessage()]);
}
?>

Ao aceder no navegador a http://localhost/meu_restaurante/obter_pratos.php, o resultado será um JSON estruturado com a lista de pratos.

Passo 3: Alterações Já Efetuadas no Projeto Android (Kotlin)
Para que o seu código Android consuma este JSON automaticamente, realizámos as seguintes alterações no projeto:
1.
Permissões de Rede ( AndroidManifest.xml):
◦
Adicionada a permissão <uses-permission android:name="android.permission.INTERNET" />.
◦
Adicionado android:usesCleartextTraffic="true" para permitir conexões HTTP durante os testes locais.
2.
Dependências Retrofit e Gson ( build.gradle.kts):
◦
Adicionados os pacotes com.squareup.retrofit2:retrofit e com.squareup.retrofit2:converter-gson.
3.
Cliente de Rede ( ApiService.kt):
◦
Criada a interface com o endpoint obter_pratos.php.
◦
Configurado o RetrofitClient apontando para o URL http://10.0.2.2/meu_restaurante/ (no emulador Android, o endereço 10.0.2.2 aponta diretamente para o localhost da sua máquina).
4.
Carregamento Dinâmico no Compose ( MainActivity.kt):
◦
Atualizado o composable RestauranteApp() com LaunchedEffect para procurar os dados ao servidor PHP. Se o servidor estiver indisponível ou offline, a aplicação utiliza a lista estática como segurança/fallback.


💡 Dicas Importantes para Testes
•
Se usar o Emulador do Android Studio: Mantenha a URL Base como http://10.0.2.2/meu_restaurante/ em  ApiService.kt.
•
Se usar um Telemóvel Físico via Wi-Fi: Altere 10.0.2.2 para o endereço IP local do seu computador na rede Wi-Fi (exemplo: http://192.168.1.100/meu_restaurante/).
